# ADR 0001 · Native PowerPoint export

Use python-pptx to map normalized IR coordinates into OOXML slide geometry. The library produces native text boxes, vector shapes, connectors, tables, embedded pictures and editable charts with spreadsheet data. Editable diagrams use native shapes, connectors and text. PowerPoint speaker notes include the slide's source references. ReportLab consumes the same intermediate representation for PDF. Automated tests reopen exports and check native object types and contents. [python-pptx documentation](https://python-pptx.readthedocs.io/en/latest/)

Branded export starts from the imported presentation package and creates slides using its existing masters, layouts and placeholders. The IR does not define authored slide masters, animations or transitions. Optional export review renders the generated PPTX in LibreOffice Impress and checks for missing or clipped text and table cells, shifted alignment, text overlap, text off the slide and font substitution.

PowerPoint charts and tables use native objects. The exporter maps supported palettes, labels, table styling and numeric alignment to Office formatting. Chart and table frame rotation and opacity are unsupported in the PowerPoint adapter. Nested rotation and opacity vary across renderers. Browser and Office use their own font engines. The PDF renderer tries to embed the TrueType face selected by the PNG renderer and falls back to Helvetica or Times when embedding is unavailable. Installed fonts and font substitutions can affect text wrapping.
